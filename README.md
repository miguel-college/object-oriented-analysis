# Object-Oriented Analysis

Made some UML Diagrams with the Theme: Hospital Triage System

- [Activity diagrams](Diagramas_Atividade_1-8.pdf): show the workflows and decisions for use cases UC01–UC08
- [Communication diagrams](Diagramas_de_Comunicacao_UC01_a_UC08.pdf): show how system objects collaborate through messages
- [Sequence diagrams](Diagramas_de_Sequencia_UC01_a_UC08.pdf): show the chronological exchange of messages between actors and system objects
- [State diagrams](Diagramas_de_Estados_1_a_8.pdf): represent the lifecycle and state transitions of key system entities
- [Package diagram](Diagrama_de_Pacotes.pdf): organizes the system into packages, such as presentation, application, domain, and infrastructure
- [Component and deployment diagrams](Diagramas_de_Componentes_e_Implantacao.pdf): describe the software components and how they are deployed and connected
